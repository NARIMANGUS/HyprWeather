# HyprWeather

HyprWeather — приложение погоды для Hyprland и Waybar.

Приложение получает данные о погоде через Open-Meteo API
и выводит их в пользовательском модуле Waybar.

## Возможности

- отображение текущего времени;
- отображение температуры воздуха;
- отображение атмосферного давления;
- отображение текущего состояния погоды;
- интеграция с Waybar.

## Технологии

- Python
- Waybar
- Hyprland
- Open-Meteo API
- Git


## Интеграция с Waybar

Для отображения погодных данных используется пользовательский можуль 'custom/weather'.

Модуль запускает Python-скрипт раз в 60 секнуд и ожидает  результат в формате JSON.

Пример конфигурации Waybar находится в 'waybar/config.jsonc'
