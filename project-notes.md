# Project Notes

## Идея проекта

Создать приложение для отображения погодной информации
в панели Waybar рабочего окружения Hyprland.

## Текущая схема

Waybar -> weather.py -> Open-Meteo API

## План

Первая версия приложения должна:

- получать текущую погоду;
- получать температуру воздуха;
- получать атмосферное давление;
- преобразовывать weather code в понятное описание;
- возвращать данные в JSON для Waybar.
